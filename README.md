# Q-Rover Study · 센서와 비전을 결합한 Arduino 로버

Arduino UNO Q에서 거리 센서와 카메라 객체 인식을 연결하는 두 차시 실습입니다. 전방 거리 센서가 장애물을 감지하거나 카메라가 지정한 객체를 인식하면 로버가 정지합니다.

## 설계와 구현

| 구성 | 책임 | 확인할 코드 |
| --- | --- | --- |
| MCU | VL53L0X 거리 판정, 두 입력 결합, 모터 구동과 제동 | [Arduino 스케치](q-rover-02/sketch/sketch.ino) |
| MPU | 카메라 객체 인식, 판정 상태 전송, 디버깅 화면 연동 | [Python 앱](q-rover-02/python/main.py) |
| 웹 UI | 디버깅용 거리·검출·정지 상태 표시 | [웹 화면 소스](q-rover-02/assets/) |

거리 센서값은 MCU에서 직접 판정합니다. MPU는 카메라 판정이 바뀔 때만 Arduino Bridge로 상태를 보냅니다. 일시적인 미검출 때 상태가 계속 뒤집히지 않도록, 최근에 객체를 본 시각을 기준으로 판정 유지 시간을 둡니다.

## 실습과 검증

1. [1차시](q-rover-01/)에서 PWM으로 모터를 구동합니다.
2. [2차시 실습 문서](q-rover-02/README.md)의 안내에 따라 Arduino App Lab에서 거리 센서와 카메라를 설정합니다.
3. 센서 가까이에 장애물을 뒀을 때와 센서 범위 밖에서 카메라에 물병만 보였을 때를 구분해, 각 입력이 정지와 재출발에 주는 영향을 확인합니다.

**사용 기술** · Arduino UNO Q, C++, Python, VL53L0X, Arduino Bridge
